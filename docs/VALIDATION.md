## Shared detector, roof and Rust desktop follow-up

The existing Command detector is shared across modes while preserving each loading lattice. Eleven selected prepared vanilla 1.12.2 view-10 trials record repeated input cycles. Mob matched 1902/1902 sampled spawner-entry states. Iron matched 2623/2625 pre-village states and produced 2546/2542 new golems at the predicted block in paired receiver-equipped trials; it requires a linked Nether receiver. Transition mismatches and failed shaded/no-receiver fixtures were retained privately. Fortune harvesting remains unverified; Gold manual/exact trials had zero exact selected-state matches, so their automatic outcomes are not calibrated.

Eight prepared Mob roof trials include actual first-position matches for all six species, saved daylight/light-zero and height-bound checks. Witch sampler states matched 1708/1710, with two transition mismatches retained. A no-input control was comparable to intervention; this does not establish a production boost. Bottom slabs are opaque and reject roof-top spawning in native method probes. Survival construction, other view distances and long-term yields remain open.

The Rust frontend reuses the headless backend shared with Tkinter. Release build, 19 RNG tests, four desktop tests, six worker checks and 12 affected regression scripts passed in the research workspace. All four modes completed actual terrain-scanned searches; a native-dialog Gold export matched the independent headless result’s full block/entity NBT.
